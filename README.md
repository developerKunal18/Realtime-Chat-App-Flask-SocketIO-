# Realtime Chat App

A simple realtime chat application using Flask and SocketIO.

## Features
- Realtime messaging
- Live updates
- Event-driven communication
- WebSocket basics

## Technologies Used
- Python
- Flask
- Flask-SocketIO
- HTML
- JavaScript

## Installation

pip install flask flask-socketio

## Run

python app.py

Open browser:
http://127.0.0.1:5000

## Purpose
focuses on realtime communication and WebSocket programming.
